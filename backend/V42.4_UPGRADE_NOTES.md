# V42.4 Upgrade Notes

## Scope

V42.4 is a system-integrity upgrade built on V42.3. It does not increase the AI request ceiling.

### Hard AI budget

- `MOLTBOOK_AI_REQUEST_BUDGET` is clamped to **1–50** per scan cycle.
- Setting the Render environment variable above 50 cannot increase the actual budget.
- `ai_requests_used`, `ai_requests_remaining`, `ai_request_budget`, and `ai_request_budget_max` expose the contract.

### Batch reliability

- `MOLTBOOK_AI_BATCH_SIZE` is clamped to **1–2**.
- Default remains **1** for reliability with the paid OpenRouter model.
- Retry telemetry now exposes `ai_retry_batches` and `ai_retry_successes`.

### Version integrity

- `backend/VERSION` is now authoritative for the FastAPI version.
- Root and health responses therefore report the same release version as the repository.

### Documentation and tests

- README and `.env.example` updated for V42.4.
- Legacy V39 budget assertions were replaced with V42.4 contract tests.
- Test suite result: **25 passed**.

## Intentionally not changed

- The AI request ceiling remains 50.
- Batch size remains conservative at 1 by default.
- No new autonomous posting behavior was enabled.
- API authentication and persistent research telemetry remain candidates for the next security/observability upgrade.
