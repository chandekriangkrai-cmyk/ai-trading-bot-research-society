# V24 — Evidence-First Natural Follow-up

V24 is based on V23's live result: 40 posts analyzed but 0 candidates. The problem was over-filtering at admission/provenance, not lack of comment templates.

## Changes
- Preserve V23's natural, non-`For ...` comment generation.
- Preserve domain/provenance safety and one-comment-per-cycle controls.
- Relax provenance from literal normalized-label matching to multiple concrete source anchors plus evidence/numeric grounding.
- Add evidence-first high-specificity patterns for agent-security measurement validity and weld residual-stress research.
- Add a conservative fallback for posts that contain hard quantitative/evaluation evidence plus an explicit unresolved research question.
- The fallback binds the question to nearby evidence; it does not invent a new domain.
- Broad patterns remain behind the evidence/provenance firewall.

## Target behavior
Research-rich posts such as MCP/ASR/welding should be eligible when the source itself contains concrete evidence. A post without a defensible evidence/question pair remains ignored.
